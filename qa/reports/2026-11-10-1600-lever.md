## Defects

1. **High, fixed**: Lever location suggestion never picked. Steps: LV_FILL with a location. Expected: hidden
   `selectedLocation` set. Actual: empty; `lvFill` still reported `location` filled. Cause: Lever searches on
   `keydown`; the code sent only `keyup`, and returned true on typed text. Fix: `src/content/ats/lever.ts:118-119`
   (dispatch keydown + keyup), `:126` and `:133` (success only when picked). `tests/lever.test.ts` 3/3 pass; build ok.
2. **Medium, open**: no job description on `/apply`, so company-motivation questions get no answer.
   `src/shared/ats/lever-flow.ts:69` builds answers from the `/apply` page only. Suggest fetching the posting page
   text (URL without `/apply`).
3. **Low, open**: backend unreachable makes `buildAnswers` throw out of `runLeverApply` (`lever-flow.ts:69`) rather
   than ending `needs_me`.
4. **QA tooling**: harness sent `resume_text: ''`, making every experience question `missing`. `scripts/qa-harness.ts`
   now accepts `resumeText`.

## Recommendations

1. Pass the posting's description to the AI on Lever (defect 2): answers the "why us" question on most Lever forms.
2. Catch backend errors in `runLeverApply` and report `needs_me` (defect 3).
3. Personal-opinion questions will stay NEEDS_USER_INPUT; consider a saved answer in the answer bank.
